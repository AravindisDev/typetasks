# TypeTasks 🚀

A type-safe task tracker built using plain HTML, CSS, and TypeScript, demonstrating robust data modeling and type-safe DOM manipulation.

## Live Demo
🔗 [View Live App](https://aravindisdev.github.io/typetasks/)

## Features
- **Strictly Typed Model:** Guarantees every task maintains a valid state (`todo`, `in-progress`, `done`).
- **Interactive UI:** Add tasks with initial statuses, filter by state using responsive chips, advance task progress, and remove tasks.
- **Zero Frameworks:** Built with vanilla HTML5, modern CSS, and modular TypeScript compiled directly to ES modules.
